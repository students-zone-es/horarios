# Horarios y tareas

Editor de horarios de clase y gestor de entregas para centros de FP. Es una web instalable (PWA), funciona sin conexión y **no necesita cuenta ni servidor**.

## Para tutores
- Crea **varios horarios** (1º DAM, 2º DAM, 1º/2º DAW u otros) a partir de plantillas o en blanco.
- Cada horario tiene sus **días, franjas, asignaturas y clases** (profesor y aula incluidos).
- Elige entre **6 temas y 3 diseños**, cambia tipografía y colores y añade el **logo del centro**.
- **Exporta a PNG o JPG** en alta resolución.
- **Comparte** un horario con otros tutores como archivo `.json` (Exportar horario / Importar horario).

## Para estudiantes
- Ve el horario del día, con la clase en curso.
- Lleva tus **entregas y exámenes** con avisos de lo urgente.
- Importa el **calendario de Moodle** (`.ics`) para traer fechas automáticamente.
- Instálala en el móvil desde el navegador («Instalar» / «Añadir a pantalla de inicio»).

## Privacidad
Todo se guarda **solo en tu navegador**. No se envía nada a ningún servidor. Para cambiar de dispositivo, exporta una copia e impórtala en el otro.

## Límites
- Sin servidor no hay avisos con la app cerrada: los avisos salen al abrirla y mientras está abierta.
- Los horarios y tareas no se sincronizan solos entre dispositivos.
